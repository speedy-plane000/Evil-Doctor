# Система окончания игры с антидотом

## Описание
Эта система добавляет в игру механику окончания с выбором:
1. **Без антидота** - смерть при выходе на солнце
2. **С антидотом** - шанс спастись, введя антидот в течение 5 секунд

## Компоненты системы

### 1. BottlePickup.cs
**Назначение:** Скрипт для подбора бутылки с антидотом
**Размещение:** На объекте `bottle_green` на 3-м этаже
**Настройки:**
- `pickupEffect` - визуальный эффект при подборе (опционально)
- `pickupSound` - звук при подборе (опционально)
- `pickupMessage` - сообщение при подборе
- `messageDuration` - длительность сообщения

### 2. EndGameTrigger.cs
**Назначение:** Триггер для запуска процесса окончания игры
**Размещение:** На лестнице в конце или на зеленом кубе (основа мира)
**Настройки:**
- `isOneTimeTrigger` - срабатывает только один раз
- `triggerDelay` - задержка перед запуском
- `visualHint` - визуальная подсказка (например, светящаяся область)
- `triggerMessage` - сообщение при активации

### 3. EndGameManager.cs
**Назначение:** Главный менеджер процесса окончания игры
**Размещение:** На сцене в единственном экземпляре (рекомендуется создать пустой GameObject)
**Настройки:**
- `fadeDuration` - время полного затемнения экрана (5 секунд)
- `antidoteInputTime` - время для ввода антидота (5 секунд)
- UI элементы (настраиваются автоматически через EndGameUISetup)
- Цвета сообщений
- Тексты сообщений

### 4. EndGameUISetup.cs
**Назначение:** Автоматическая настройка UI для системы окончания игры
**Размещение:** На том же GameObject, что и EndGameManager
**Использование:** Автоматически создает Canvas и UI элементы при запуске

## Инструкция по настройке

### Шаг 1: Создание EndGameManager
1. Создайте пустой GameObject в сцене и назовите его "EndGameManager"
2. Добавьте компонент `EndGameManager`
3. Добавьте компонент `EndGameUISetup` (UI настроится автоматически)

### Шаг 2: Создание бутылки с антидотом
1. Создайте объект `bottle_green` на 3-м этаже (например, цилиндр или куб)
2. Добавьте компонент `BottlePickup`
3. Настройте коллайдер (должен быть триггером)
4. При желании добавьте визуальные эффекты и звуки

### Шаг 3: Создание триггеров окончания
1. Выберите объект лестницы в конце или зеленый куб (основа мира)
2. Добавьте компонент `EndGameTrigger`
3. Настройте BoxCollider как триггер
4. При желании добавьте визуальную подсказку

### Шаг 4: Настройка параметров (опционально)
В инспекторе EndGameManager можно настроить:
- Время затемнения и ввода антидота
- Цвета сообщений
- Тексты сообщений (можно локализовать)

## Логика работы

### Сценарий 1: Антидот не подобран
1. Игрок входит в триггер окончания
2. Появляется сообщение: "Вы вышли на солнце и умерли..."
3. Экран постепенно темнеет в течение 5 секунд
4. Игра завершается

### Сценарий 2: Антидот подобран, но не введен
1. Игрок входит в триггер окончания
2. Появляется сообщение: "Нажмите ПРОБЕЛ, чтобы ввести антидот"
3. Запускается таймер на 5 секунд
4. Если игрок не нажимает ПРОБЕЛ:
   - В последние 2 секунды экран начинает темнеть
   - По истечении времени: "Вы вышли на солнце и умерли..."
   - Игра завершается

### Сценарий 3: Антидот подобран и введен
1. Игрок входит в триггер окончания
2. Появляется сообщение: "Нажмите ПРОБЕЛ, чтобы ввести антидот"
3. Игрок нажимает ПРОБЕЛ в течение 5 секунд
4. Появляется сообщение: "Вы успешно сбежали от злого доктора!"
5. Затемнение экрана отменяется
6. Игра завершается успешно

## Тестирование

### Методы для тестирования (в редакторе):
1. **Проверить сбор антидота:** Подойти к bottle_green
2. **Запустить окончание игры:** Войти в триггер EndGameTrigger
3. **Сбросить состояние:** Использовать методы Reset в компонентах

### Консольные сообщения:
Система выводит отладочные сообщения в консоль:
- `[BottlePickup] Антидот подобран игроком`
- `[EndGameManager] Антидот собран: true/false`
- `[EndGameManager] Игрок умер без антидота`
- `[EndGameManager] Игрок не успел ввести антидот`
- `[EndGameManager] Игрок успешно сбежал!`

## Расширение системы

### Добавление новых сообщений:
Измените текстовые поля в EndGameManager:
- `noAntidoteMessage`
- `antidotePromptMessage`
- `timeoutMessage`
- `successMessage`

### Изменение времени:
Настройте в EndGameManager:
- `fadeDuration` - время затемнения
- `antidoteInputTime` - время для ввода антидота

### Добавление визуальных эффектов:
1. Создайте префабы эффектов
2. Назначьте их в соответствующие поля:
   - `pickupEffect` в BottlePickup
   - `visualHint` в EndGameTrigger

## Примечания
- Система использует TextMeshPro для текста (входит в стандартные пакеты Unity)
- Для работы требуется импортировать TextMeshPro через Package Manager
- Все компоненты имеют методы Reset для тестирования
- UI автоматически создается при наличии EndGameUISetup
